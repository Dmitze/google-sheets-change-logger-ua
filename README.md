# 📌 Логи змін для Google Sheets

[![Version](https://img.shields.io/badge/version-v1.0.0-blue.svg)](#)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](#-ліцензія)
[![Language](https://img.shields.io/badge/lang-ukrainian-yellow.svg)](#)

Автоматичне **підсвічування** та **логування змін** у Google Таблицях з можливістю щоденного очищення.  
Скрипт допомагає відслідковувати, хто і коли редагував дані, а також виділяє зміни кольорами для зручності.

---

## ✨ Можливості

- 🔦 **Підсвічування змін**:
  - 🟩 Додано значення
  - 🟥 Видалено значення
  - 🟨 Змінено значення

- 📝 **Логування**:
  - Час зміни
  - Користувач (ім’я або email)
  - Аркуш та клітинка (з гіперпосиланням)
  - Тип дії (додано / видалено / змінено)
  - Старе та нове значення
  - Місце для формули та позначки “важлива зміна”

- 🧹 **Очищення підсвічувань**:
  - Ручне очищення через меню
  - Автоматичне очищення старих змін (>24 год)
  - Повне автоочищення щодня о 23:00 за Києвом

- 👤 **Користувацьке ім’я**:
  - Можливість ввести або змінити своє ім’я/позивний для логів

## 📂 Структура меню

Після встановлення скрипта у Google Sheets з’явиться нове меню:

## 📌 Логи змін ├─ Очистити всі підсвічування 
├─ Встановити автоочищення (щодня о 23:00) ├─────────────── ├─ Створити аркуш логів └─ Ввести/змінити ім’я користувача


---

## 🚀 Встановлення

1. Відкрий Google Таблицю.
2. Перейдіть у **Extensions → Apps Script**.
3. Скопіюйте вміст `Code.gs` у редактор.
4. Збережіть проєкт.
5. Оновіть сторінку таблиці — у меню з’явиться пункт **📌 Логи змін**.
6. Виконайте пункт **Створити аркуш логів**, щоб створити аркуш `Лог змін`.

---

## ⚙️ Використання

- **Редагуйте дані** — усі зміни будуть підсвічені кольорами.
- **Переглядайте аркуш `Лог змін`** — там зберігається історія змін.
- **Очищуйте підсвічування**:
  - вручну через меню,
  - або автоматично (щодня о 23:00 за Києвом).

## 🛠 Налаштування

- **Ігноровані колонки**:  
  `Постійний ID`, `Ідентифікатор`, `QR-код`, `QR`, `link`, `Посилання на QR`

- **Тривалість підсвічування**:  
  24 години (можна змінити у константі `HIGHLIGHT_DURATION_HOURS`)

- **Час автоочищення**:  
  23:00 за Києвом (налаштовується у `installDailyCleanupTrigger`)
